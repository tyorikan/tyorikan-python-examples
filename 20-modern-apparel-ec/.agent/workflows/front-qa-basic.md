# フロントエンド基本 QA テスト

## 受入基準
- トップページから商品詳細ページへの遷移が正常に行えること
- 商品詳細ページに商品情報（画像、テキスト等）が正しく表示されること
- 商品詳細ページからカテゴリ一覧ページへの遷移が正常に行えること
- カテゴリ一覧ページに商品リストが正しく表示されること
- 全行程でブラウザコンソールに重大なエラーが表示されないこと
- 画像が正しくロードされ、リンク切れがないこと

## 1. 開発サーバーの起動

// turbo
1. フロントエンドの開発サーバーを起動する:
   ```bash
   cd frontend && npm run dev
   ```
// turbo
2. サーバーが応答するまで待機する:
   ```bash
   timeout 30s bash -c 'until curl -s http://localhost:5173 > /dev/null; do sleep 1; done'
   ```

## 2. トップページの確認

1. ブラウザで `http://localhost:5173` を開く。
2. スクリーンショットを撮る。
3. 以下を確認する:
   - ヒーローセクションや商品リストが表示されているか
   - コンソールにエラーログ（404, Uncaught Exceptions 等）が出ていないか

## 3. 商品詳細ページへの遷移

1. トップページの最初の商品カードをクリックする。
2. 2 秒待機してスクリーンショットを撮る。
3. 以下を確認する:
   - URL が `/products/{id}` 形式に変化したか
   - 商品画像が正しく表示されているか（壊れた画像アイコンになっていないか）
   - 商品名、価格、説明文が読み取れるか
   - コンソールにエラーが表示されていないか

## 4. カテゴリ一覧ページへの遷移

1. ヘッダーのナビゲーションからカテゴリリンク（例: MEN, WOMEN）をクリックする。
2. 2 秒待機してスクリーンショットを撮る。
3. 以下を確認する:
   - URL が `/categories/{category}` 形式に変化したか
   - 選択したカテゴリの商品一覧が表示されているか
   - 商品カードのグリッド表示が崩れていないか
   - コンソールエラーがないか

## 5. 最終評価

以下の観点でテスト結果を評価し、レポートする:
- クリティカルなバグ（画面が真っ白、操作不能、クラッシュ）はあったか
- マイナーなバグ（レイアウトのズレ、テキストの誤字、軽微な表示崩れ）はあったか
- UI/UX の観点で「使いにくい」「分かりにくい」と感じた点はあったか

**最終判定**: 【承認】または【却下】の判定と、その理由を詳細に記述する。修正が必要な場合は、具体的な修正箇所を指摘する。
