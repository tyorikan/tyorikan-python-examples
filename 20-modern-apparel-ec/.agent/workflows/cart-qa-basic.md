# カート機能 QA テスト

## 受入基準
- 商品詳細ページからカラー・サイズを選択し、「カートに追加」で商品が追加されること
- カートページに追加した商品が正しく表示されていること（商品名、画像、カラー・サイズ、価格）
- カートページで数量変更（+/-）が行え、合計金額が正しく再計算されること
- 削除ボタンで商品をカートから削除できること
- カートが空になった場合に、空である旨のメッセージが表示されること
- 一連の操作中にコンソールエラーが発生しないこと

## 1. 開発サーバーの起動

// turbo
1. バックエンドとフロントエンドのサーバーを起動する:
   ```bash
   make backend > /dev/null 2>&1 & cd frontend && npm run dev
   ```
// turbo
2. フロントエンドサーバーが応答するまで待機する:
   ```bash
   timeout 30s bash -c 'until curl -s http://localhost:5173 > /dev/null; do sleep 1; done'
   ```

## 2. トップページの確認

1. ブラウザで `http://localhost:5173` を開く。
2. スクリーンショットを撮り、トップページが正しく表示されているか確認する。

## 3. 商品をカートに追加

1. トップページの最初の商品カードをクリックして詳細画面に遷移する。
2. カラーを選択する。
3. サイズを選択する。
4. 「カートに追加」ボタンをクリックする。
5. 2 秒待機してスクリーンショットを撮る。
6. 以下を確認する:
   - ボタンが成功の表示に変わったか
   - コンソールエラーは発生していないか

## 4. カートページの確認

1. `http://localhost:5173/cart` に遷移する。
2. 2 秒待機してスクリーンショットを撮る。
3. 以下を確認する:
   - 追加した商品（商品名、画像、選択したカラー・サイズ、価格）が正しく表示されているか
   - 合計金額は正しく計算されているか

## 5. 数量変更の確認

1. 数量増加ボタン（+）をクリックする。
2. 2 秒待機してスクリーンショットを撮る。
3. 以下を確認する:
   - 数量が増加し、商品小計・合計金額が正しく更新されているか

## 6. 商品の削除

1. 削除ボタン（ゴミ箱アイコン）をクリックする。
2. 2 秒待機してスクリーンショットを撮る。
3. 以下を確認する:
   - 商品がカートから削除されたか
   - 「Your cart is empty」などのメッセージが表示されているか
   - 小計や合計金額が 0 円または非表示になっているか

## 7. 最終評価

以下の観点でテスト結果を評価し、レポートする:
- カートへの追加、表示、数量変更、削除の全機能が問題なく動作したか
- クリティカルなバグ（金額が NaN になる、アイテムが追加されない等）はあったか

**最終判定**: 【承認】または【却下】の判定と、その理由を詳細に記述する。修正が必要な場合は、具体的な修正箇所を指摘する。
