# テスト

## テストピラミッド

| レベル | 割合 | スコープ | 速度 | ツール |
|---|---|---|---|---|
| ユニット | 70% | 単一クラス/関数 | ミリ秒 | pytest |
| インテグレーション | 20% | API + DB + スタブ | 秒 | pytest + testcontainers（Spanner エミュレータ） |
| E2E | 10% | 完全なユーザージャーニー | 分 | Playwright（ステージング環境） |

## 規約

- **テストデータ**: `polyfactory` または `factory_boy` を使用。ハードコードしたフィクスチャは禁止。
- **分離**: すべてのテストはクリーンな状態で開始する（トランザクションロールバックまたは DB リセット）。
- **モック**: 厳格に行う。ユニットテストでは DB と HTTP 呼び出しをモックする。
- **`sleep()` 禁止**: 非同期待機には `await expect(locator).toBeVisible()` を使う。
- リトライロジックではなく、**競合状態（Race Condition）を修正する**。

## CI 統合

- テスト失敗 = ビルド失敗。
- カバレッジ目標: バックエンドロジックで > 80%。
