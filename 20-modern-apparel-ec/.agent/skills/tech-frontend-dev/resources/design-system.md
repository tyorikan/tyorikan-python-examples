# Design System

## Typography
*   Font: "Inter", sans-serif.
*   Sizes: `text-sm` (body), `text-xl` (headings).

## Colors (Tailwind)
*   Primary: `slate-900`
*   Secondary: `slate-600`
*   Accent: `indigo-600`
*   Danger: `red-600`

## Components
*   Use `shadcn/ui` style components.
*   Buttons: `rounded-md`, `px-4`, `py-2`.
*   Inputs: `border`, `rounded-md`, `focus:ring-2`.
